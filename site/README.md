# Lexicon browser

This directory contains the static browser for the Wargaming Design Lexicon. It is deliberately backend-free so it can be hosted with GitHub Pages or used as a lightweight local reference.

The browser reads the repository data rather than maintaining a second hand-edited copy. Canonical releases are generated from the validated master dataset; do not manually renumber WG identifiers.

Development targets include search, category browsing, mechanic detail views, design-problem navigation, comparison and Designer Mode. The packaged v281 release contains the richer offline build while repository data migration is kept separate from interface changes.
